# Dataset notes

Place licensed source images in `data/raw/`. Images and generated variants are intentionally excluded from Git.

For every collected image, keep a separate dataset log with at least:

- `image_id`
- source/author and license or confirmation that it is self-captured
- capture date (if relevant)
- coarse scene type: indoor/outdoor
- tags: low-light, small-object, glass, reflective, occlusion, boundary, etc.

Do not publish faces, private information, copyrighted datasets, or location metadata without permission. Remove EXIF metadata before public release when it may contain sensitive information.
